My Application: An Application used for entering past or future vacations and listing excursions I'd like to do or have done on said vacations.

The app functions as follows:
1. On start, you are presented with a title screen and a button that takes you into the app. Click this button to proceed.
2. The second screen is a list of all vacations you've previously entered, and has a button to enter new ones. Click on the names
of previous vacations to see more details.
3. Clicking a previous vacation or the add new vacation button will both take you to the same screen, although if you click a previous
vacation it's info will populate. This screen allows you to see, edit, add, and delete all vacation information as well as any attached excursions.
This screen also has a menu that will allow you to add alerts for your vacations and share the details with others. 
4. Clicking on an excursion or the add button in the bottom right will take you to the excursion screen, which will be populated if you are
viewing a current excursion. This screen allows you to see, edit, add, and delete all excursions information, as well as add an alert for the
selected excursion.
